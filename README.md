# 血圧記録アプリ

血圧・脈拍・服薬・症状メモを SQLite に保存する tkinter アプリです。

このアプリは医療診断を行うものではありません。記録を整理し、医師に相談するための補助ツールです。

## 起動方法

```powershell
& "D:\Dev\venvs\venv_bptrack312\Scripts\python.exe" main.py
```

## Ver.0.6 でできること

- SQLite DB の自動作成
- 1日分の記録入力
- 保存
- 一覧表示
- 選択行読み込み
- 更新
- 削除
- CSV 出力
- 期間指定表示
- グラフ表示
- Hi-Level Sample 抽出
- Low-Level Sample 抽出
- マークポイント表示
- 診察用 HTML レポート出力
- 食事、塩分、カフェイン、外出、入浴、睡眠の質、ストレス度などの任意記録
- 条件別のトリガー分析表示
- 記録日欄の今日の日付初期表示
- 記録日欄クリックによるミニカレンダー選択
- コンサータ時刻、メトグルコ回数、前回一部コピー、メモテンプレートの入力補助
- 保存・更新前の確認表示
- 手動バックアップ作成
- DB整合性チェック表示
- 姿勢変化イベント記録
- イベント前後の収縮期・拡張期差分と確認表示
- 帰宅後データ記録
- 帰宅時、しゃがみ込み、立ち上がり直後、1分後、3分後、就寝時の血圧・脈拍記録
- 帰宅時Hからしゃがみ込みH、しゃがみ込みHから各立ち上がり時点Hへの差分表示
- 到着時、昼食前、食事内容、昼食後の任意記録欄

## データ保存先

- DB: `data/bp_tracker.sqlite3`
- CSV: `exports/`
- 診察用HTMLレポート: `reports/`
- バックアップ: `backups/`

## 注意

画面上の「注意候補」「確認推奨」は診断ではありません。
記録を整理し、医師に相談するための目安として使ってください。
